## 🚀 Featured Projects

### 🛡️ [QAVACH](https://github.com/snbhowmik/QAVACH) — Post-Quantum E-Governance Platform
> *QAVACH (Hindi for "Armour") is a next-generation digital identity & document verification platform for Indian e-governance.*

Built with **Flutter · FastAPI · Next.js · React** — it implements **NIST FIPS 203/204/205** post-quantum cryptography standards (ML-KEM, ML-DSA, SLH-DSA) to protect against "harvest now, decrypt later" quantum threats. Citizens' credentials never leave their device — verification happens locally via an on-device Open Policy Agent (OPA) WASM engine.

`TypeScript` `Python` `Flutter` `Post-Quantum Cryptography` `Zero-Trust`

---

### 🏥 [Project C.A.R.E - X](https://github.com/snbhowmik/care-x) — Decentralized Healthcare Trust Layer
> *Blockchain-based healthcare system for secure, privacy-preserving sharing of medical data.*

Integrates **Ethereum smart contracts, IPFS, FastAPI, React, and Next.js** to give patients full control over their records and consent. All access and sharing events are logged on-chain for immutable auditability.

`TypeScript` `Solidity` `FastAPI` `React` `IPFS` `Blockchain`

---

### 🚨 [Project C.A.R.E](https://github.com/snbhowmik/Project-CARE) — ER Clinical Action & Response Engine
> *Smart mission-control system for emergency rooms in rural hospitals.*

Real-time patient prioritization using color-coded triage (Critical 🔴 / Urgent 🟠 / Stable 🟢), edge computing for low-latency alerts, cloud-based learning from anonymized cases, and **FHIR** interoperability.

`Svelte` `Edge Computing` `Healthcare` `FHIR`
